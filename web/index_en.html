System information

Physical CAN reception is active. Modbus TCP: port 502, Unit ID 1, FC03 reads. Green indicates recent valid reads by a Modbus client, including diagnostic software. Test mode uses a separate vcanhub bus and a local test Modbus server.

Enter addresses separately in the data, status and age register columns, then click Save configuration. The table scrolls horizontally.

Protocol v3: choose a unique node ID (1–95) and enter the Modbus register addresses. Measurement positions are allocated permanently in order (1–24). CAN IDs, slots, int16 and little-endian are automatic. Deleting a measurement does not renumber or reuse its position. Match positions to the firmware documentation. Existing v1/v2 modules remain supported. Status bits and Modbus registers are unchanged.

Reading network settings…

Use an unused address outside the DHCP pool or reserve it in the router. Restart the RPi after saving. Then open /can at the new address and update the HMI device address. Password and module settings are retained.

Local backup

Download module configuration, register mappings and backup settings. Passwords and measurement history are not included.

Upload backup from computer

Merge preserves existing settings, including empty fields. Modules match by CAN channel and ID; signals by frame ID and start byte (or name without a frame). Replace overwrites modules and remote backup settings; the login password is retained.

A copy of the previous configuration is saved before import. Changes activate automatically in CAN, Modbus and diagnostics.
