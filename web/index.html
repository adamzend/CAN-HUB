Informacje systemowe

Odbiór fizycznego CAN jest aktywny. Modbus TCP: port 502, Unit ID 1, odczyt FC03. Zielona lampka oznacza aktualne poprawne odczyty klienta Modbus (także programu diagnostycznego). Tryb testowy korzysta z osobnej magistrali vcanhub i serwera Modbus wewnątrz Raspberry.

Adresy wpisuj osobno w kolumnach „Modbus rejestr danych”, „Modbus rejestr statusu” i „Modbus rejestr wieku [s]”, następnie kliknij „Zapisz konfigurację”. Tabelę można przewijać poziomo.

Protokół v3: wybierz unikalne ID modułu (1–95) i wpisz adresy rejestrów Modbus. Pozycje pomiarów są przydzielane na stałe kolejno (1–24). ID ramek, slot, int16 i little-endian są automatyczne. Usunięcie pomiaru nie przesuwa innych pozycji i nie przydziela ponownie usuniętej. Pozycje muszą odpowiadać instrukcji programu ESP32. Moduły v1/v2 nadal działają. Znaczenie statusów i rejestry Modbus pozostają bez zmian.

Adres IP CAN HUB

Odczytywanie ustawień sieci…

Użyj wolnego adresu poza pulą DHCP albo z rezerwacją w routerze. Zapis wymaga restartu RPi. Po restarcie otwórz nowy adres /can i zmień adres CAN HUB w HMI. Hasło i konfiguracja modułów pozostają bez zmian.

Kopia lokalna

Pobierz konfigurację modułów, mapowania rejestrów i ustawienia backupu. Kopia nie zawiera haseł ani historii pomiarów.

Wgraj backup z komputera

Uzupełnianie zachowuje wszystkie obecne ustawienia, także puste pola. Moduł rozpoznajemy po kanale CAN i ID, sygnał po ID ramki i bajcie początkowym (bez ramki: po nazwie). Nadpisanie zastępuje moduły i ustawienia backupu zdalnego; hasło logowania pozostaje bez zmian.

Przed zapisem powstaje kopia poprzedniej konfiguracji. Import aktywuje zmiany automatycznie w CAN, Modbusie i diagnostyce.
